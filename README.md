# Main repository for all in-class labs for SEIS 745 Data Lake Engineering

Getting started registering for our AWS lab environment and GitHub?  Then open the setup-docs folder for instructions.

Already set up and looking to complete an in-class lab?  Navigate to the appropriate lab folder for that class, e.g. lab-01-aws-emr-connecting-to-cloud-storage for our first lab.  Lab instructions are included in the README.  Open in a human-friendly markdown viewer, either directly in the lab folder in GitHub or in your GitHub VS Code Codespace via 'Open Preview'.

Lab instructions will generally leverage a shared infrastructure folder which is reused across labs.  For instance, one lab may require EMR and rely on the 'infra-emr-cluster' folder. Another lab might require Kafka and rely on the 'infra-rds-kafka-dbez' lab.
